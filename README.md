# Monomerinių baltymų termodinaminių parametrų prognozavimas taikant WSME modelį

Šioje repozitorijoje pateikiamas programinis kodas, naudotas bakalauro baigiamajame darbe. Tyrimo tikslas – sukurti ir parametrizuoti molekulinės dinamikos simuliacijomis Gō tipo (WSME) modelį, galintį prognozuoti monomerinių baltymų susilankstymo termodinaminius parametrus.

## Repozitorijos struktūra (Darbo priedai)

Žemiau pateikiami failai atitinka baigiamajame darbe nurodytus programinio kodo priedus:

* **Priedas B** (`Priedas_B_Baltymu_3D_strukturu_sulyginimo_kodas`) – Baltymų 3D struktūrų sulyginimo kodas.
* **Priedas C** (`Priedas_C_WSME_skaiciavimu_tikrinimo_kodas_naudojant_eksponenciu_sudeties_metoda`) – WSME skaičiavimų tikrinimo kodas naudojant eksponenčių sudėties metodą.
* **Priedas D** (`Priedas_D_WSME_skaiciavimu_tikrinimo_kodas_naudojant_matricu_pernasos_metoda`) – WSME skaičiavimų tikrinimo kodas naudojant matricų pernašos metodą.
* **Priedas E** (`Priedas_E_Amber_molekulines_dinamikos_skaiciavimu_kodas`) – AMBER molekulinės dinamikos skaičiavimų (simuliacijų) paleidimo kodas.
* **Priedas F** (`Priedas_F_MMPBSA_analizes_kodas`) – MMPBSA analizės kodas, skirtas sekai specifinių energijų matricų išgavimui.
* **Priedas G** (`Priedas_G_WSME12.py_kodas`) – Bazinio 26 parametrų WSME12 modelio algoritmas ir optimizacijos kodas.
* **Priedas H** (`Priedas_H_WSME13.py_kodas`) – Hibridinio 59 parametrų WSME13 modelio algoritmas.
